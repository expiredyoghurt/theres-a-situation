5. Key information 1

9. Key information 5

13. Name

### Pupil experience
- Each part displays exactly **3 selectable options**.
- Each part also has a **blank text field** for the pupil’s own response.
- Typing in the blank field automatically selects the custom-response path for that part.
- The live report preview assembles selected/custom responses in order.
- The pupil’s name is now part of the 13-part builder, with formal/informal examples and server-side sign-off validation retained.

### Teacher/admin experience
- Added **Edit 13 parts** per case. Teachers/admins can edit labels, all three options, and the correct option manually.
- Saving manual edits marks the case as Draft and clears prior approval so the edited case must be reviewed before publishing.
- Added **AI regeneration per individual Step 4 part**.
- Regeneration also returns the case to Draft so changes are reviewed before publishing.

### AI generation
- Initial case generation now creates the full 13-part structure.
- Key information generation supports five required points.
- Regeneration uses focused prompts for individual parts.

### Marking
- Multiple-choice selections continue to use the answer key.
- Custom typed responses are checked with text similarity; the Own idea custom response also uses the case’s own-content keyword groups.

### Version
- Application version: **v1.6**.
